# Instagram Frontend UI

A responsive and modern frontend clone of the Instagram web and mobile interface. Built with a focus on replicating the core user experience, interactions, and aesthetic of Instagram's primary feed, stories, and navigation.

## ✨ Key Features
- **Responsive Navigation Bar:** Sticky top navigation with the Instagram logo, search bar, and quick-action icons (Home, Direct Messages, Create, Activity, Profile).
- **Stories Section:** Horizontal scrolling story ring at the top of the feed (viewable status rings for seen/unseen stories).
- **Interactive Feed:** Post cards displaying user avatars, usernames, high-quality images/videos, double-tap to like, comments section, and action buttons (like, comment, share, save).
- **Sidebar Widgets:** "Suggestions for You" section, user account switching, and footer links.
- **Dark Mode Support:** Adapts to user preference (supports both light and dark themes).

## 🚀 Getting Started

Follow these steps to run a local copy of the project on your machine.

### Prerequisites
Make sure you have Node.js and npm installed on your system.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the project directory:
   ```bash
   cd instagram-ui
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm start
   ```
